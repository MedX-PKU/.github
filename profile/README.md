### 关于我们

我们依托**北京大学软件工程国家工程研究中心**，由**马连韬**研究型助理教授指导。实验室与高校及临床机构合作，研究医疗大模型、可信 AI 与数据驱动的医学发现，致力于构建高可信、易用的工具，赋能临床决策与医学科研。

### 研究方向

| 方向 | 我们关注的问题 |
| :--- | :--- |
| **医疗大模型与智能体** | 多模态医疗大模型、多智能体协作临床决策与科研自动化（Medical AI Scientist）。 |
| **可信医疗人工智能** | 面向临床预测的可解释深度学习、人机协作与交互可靠性。 |
| **AI for Science（医学方向）** | 电子病历数据驱动的科学发现、AI 赋能用药指导与循证医学。 |

### 特色项目

| 项目 | 简介 | 体验 |
| :--- | :--- | :--- |
| **[HealthFlow](https://github.com/yhzhu99/HealthFlow)** | 面向电子病历分析全流程自动化的多智能体框架。 | [在线演示](https://healthflow.medx-pku.com/) |
| **[MedAgentBoard](https://github.com/yhzhu99/MedAgentBoard)** | 评测医疗多智能体协作能力的基准。 | [在线演示](https://medagentboard.netlify.app/) |
| **[ColaCare](https://github.com/PKU-AICare/ColaCare)** | 大语言模型驱动的多智能体电子病历建模框架。 | [在线演示](https://colacare.netlify.app/) |
| **[OneEHR](https://github.com/MedX-PKU/OneEHR)** | 面向纵向电子病历分析与可复现建模实验的工具包。 | [项目网站](https://medx-pku.github.io/OneEHR/) |
