## 关于我们

医维矩阵人工智能实验室依托北京大学软件工程国家工程研究中心，由马连韬研究型助理教授指导。实验室聚焦人工智能与医学交叉研究，与高校及临床机构合作，推动医学 AI 研究成果走向临床实践。

## 主要研究方向

- **医疗大模型与智能体**：多模态医疗大模型、多智能体协作临床决策与科研自动化（Medical AI Scientist）等。
- **可信医疗人工智能**：面向临床预测的可解释深度学习、人机协作与交互可靠性等。
- **AI for Science（医学方向）**：电子病历数据驱动的科学发现、AI 赋能用药指导、循证医学等。
